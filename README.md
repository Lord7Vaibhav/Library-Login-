# PageTurner Library: Member Login

A library-themed login system built with HTML, CSS and vanilla JavaScript.

## Features
- Responsive, library-themed UI
- Authentication: Email + Password and Google Sign-In (Supabase Auth)
- Login history stored in Supabase Postgres (Row Level Security enabled)
- Every login synced to Google Sheets (Apps Script webhook)
- Deployed on Vercel

## Tech stack
HTML, CSS, JavaScript, Supabase (Auth + Postgres), Google Apps Script, Vercel

## Run locally
1. Clone the repo
2. Add your keys in `config.js`
3. Open with VS Code Live Server (http://127.0.0.1:5500)
